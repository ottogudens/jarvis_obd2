# OBD2 HUD Live Dashboard & Copiloto IA

Aplicación Web PWA de telemetría CAN-Bus en tiempo real para smartphones en modo horizontal (Landscape Mode) dentro del vehículo.

## Características
* **Landscape HUD Mode:** Ajuste 100% libre de desplazamiento vertical/horizontal.
* **Telemetría CAN-Bus:** Gauges de RPM, Velocidad, Temperatura TCM (`221002`) y Gráfica de Turbo Boost.
* **Copiloto IA por Voz:** Integración con Gemini 3 Flash e interacción Manos Libres.
* **Despliegue fácil en Vercel:** Configuración de Serverless Function e instalación como PWA.
